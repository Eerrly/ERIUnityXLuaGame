# ERIUnityXLuaGame
***AssetBundle框架，Lua[^lua]实现业务逻辑，热更新***

### 介绍
可视化工具使用Odin[^odin]插件，序列化使用NewtonSoft.Json[^newtonsoft.json]插件
+ `[工具]`->`[SpriteAtlas Tools]` 图集工具
+ `[工具]`->`[Build Tools]` 构建工具
+ `[工具]`->`[AssetBundle Tools]` AssetBundle信息展示工具
+ `[工具]`->`[Patch Tools]` 热更工具
+ `[工具]`->`[Node Tools]` 可视化工具 `TODO`
+ `[工具]`->`[Other Tools]` 打开一些目录的其他工具

### 环境
+ **Unity2019-2021** [Unity官方地址](https://unity.com/)

### 使用
+ 运行`Main.unity`
